# Prosa User Guide

## 1. Introduction
Prosa is built for writers who need both drafting speed and project structure.

With Prosa, you can:
- Plan a manuscript using parts, chapters, and scenes.
- Draft scenes with a rich-text editor.
- Keep notes, annotations, and scene metadata.
- Use AI support for revision, translation, and consistency.
- Export in multiple formats.

## 2. The workspace overview
### What this area does
The workspace is your main writing hub.

### Where to find it
After sign-in, open **Projects** and then open a manuscript or scene.

### How to use it
1. Use the top header for:
   - Project breadcrumb
   - Global search
   - Signed-in account indicator
2. Use left navigation for:
   - Editor
   - Synopsis
   - Projects
   - Account
3. Use the center area for writing.
4. Use the right panel for story tools, notes, AI, quality, and history.

## 3. Projects and documents
### What this feature does
Prosa supports two writing containers:
- **Projects** for structured manuscripts.
- **Documents** for flexible drafts and notes.

### Where to find it
Open **Projects** from the main navigation.

### How to use Projects
1. Click **New project**.
2. Select the project from the project dropdown.
3. Rename it with **Edit name**.
4. Use entry points:
   - **Resume**: opens your last writing context.
   - **Open manuscript**: opens manuscript editor flow.
   - **Open project**: opens project workspace.
5. In **Navigator**, add and manage:
   - Parts
   - Chapters
   - Scenes
6. Reorder nodes by drag and drop.
7. Use node menu actions like rename, add child node, open scene, and delete.

### How to use Documents view
1. Switch to **Documents** tab in the start hub.
2. Choose document lists:
   - Active
   - Archived
   - Trash
3. For each document, use actions:
   - Open
   - Rename
   - Archive / Unarchive
   - Move to trash
   - Restore
   - Delete permanently (from Trash)

## 4. Using the editor
### What this feature does
The editor is where you draft and revise scene text.

### Where to find it
Open any scene from a project.

### How to use it
1. Type directly in the editor.
2. Use the toolbar for formatting:
   - Bold, italic, headings
   - Bulleted/numbered lists
   - Blockquotes
   - Links
   - Tables
   - Images (upload or URL)
   - Alignment and indentation
3. Use **Undo** and **Redo**.
4. Use **Focus mode** to reduce distractions.
5. Watch status indicators for:
   - Word count
   - Page estimate
   - Save status
   - Version snapshot notices

## 5. Organizing your writing
### What this feature does
Organization tools help you keep story intent, structure, and notes aligned.

### Where to find it
In the editor�s right panel categories.

### How to use it
1. Open **Story tools > Scene card Coach**.
2. Fill or edit scene fields:
   - Narrative purpose
   - Emotional beat
   - Key events
   - Open questions
   - POV character
   - Setting/place
   - Timeline marker
   - Tags
3. Open **Notes & tasks > Notes** for private section notes.
4. Open **Notes & tasks > Annotations** to review comments/TODOs/highlights.
5. Open **Navigator** to jump between scenes and keep manuscript order.

## 6. AI writing assistance
### What this feature does
AI helps with revision, ideation, translation, and story consistency.

### Where to find it
Editor right panel:
- **Writing > Writing tools**
- **Coach > Consistency Coach**
- **Coach > Style & quality Coach**
- **Advanced > Prompt library**
- **History tools > History**

### How to use it
1. For writing tools, select text (if needed).
2. Click an AI action.
3. Review the proposal.
4. Click **Apply** or **Discard**.
5. Review previous AI commands in **History**.
6. Use **AI Undo** or **AI Redo** when available.

## 7. Searching in a project
### What this feature does
Global search finds content across project materials.

### Where to find it
Top center of the workspace header.

### How to use it
1. Enter a query in **Search documents, pages, notes...**.
2. Optional: enable **Include outline & scene cards**.
3. Open a result to jump to the matched location.
4. Use **Clear** to reset search.

## 8. Exporting documents
### What this feature does
Export creates shareable manuscript files.

### Where to find it
In the editor: **Document actions > Export...**

### How to use it
1. Choose preset or create/update one.
2. Choose content and format.
3. Choose scope:
   - Whole manuscript
   - Current section
   - Current page
   - Selected sections
   - Current selection
4. Optional settings:
   - Title page fields
   - Table of contents depth
   - Chapter break rules
   - Template
5. Use **Preview**.
6. Click **Export**.

### Template manager
1. Click **Manage templates...**.
2. Create from a preset or duplicate an existing template.
3. Edit page size, margins, typography, header/footer, TOC, and page numbering.
4. Save template and reuse it in future exports.

## 9. Account and billing
### What this feature does
Shows your plan details and lets you upgrade or manage subscription.

### Where to find it
Open **Account** from the main navigation.

### How to use it
1. Review:
   - Current plan
   - AI usage and token budget
   - Current billing period start
2. Click upgrade button if shown.
3. Open **Billing** to:
   - Upgrade to Standard or Pro
   - Open Stripe billing portal (Manage Billing)
4. After checkout, return to Prosa and verify updated plan status.
