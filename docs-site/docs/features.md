# Prosa Feature Overview

## Core writing workflow
- Project-based manuscript workspace with **Parts, Chapters, and Scenes**.
- Fast scene drafting in a clean rich-text editor.
- **Resume writing** from your last context.
- Built-in onboarding that creates a starter structure.

## Editor experience
- Rich formatting: headings, lists, quotes, links, tables, images, alignment, indentation.
- Focus mode for distraction-free drafting.
- Autosave with save status feedback.
- Per-scene word count and page estimate.

## Organization and planning
- Navigator tree with drag-and-drop structure management.
- Scene cards for story intent, beats, metadata, and open questions.
- Section notes plus annotations (comments, TODOs, highlights).
- Project progress dashboard with goals, milestones, and writing sessions.

## AI assistance
- Selection and section rewriting tools.
- Tone changes, tighten/expand, and show-don't-tell improvements.
- Translation for selection, section, or full document.
- Next-paragraph suggestions.
- Continuity checks (character/place/timeline) with suggested fixes.
- Style and quality checks with actionable revision suggestions.
- Prompt library for reusable custom AI workflows.
- AI history with before/after details and AI undo/redo.

## Search and navigation
- Global search across documents, pages, notes, and optional metadata.
- One-click jump from search results to the exact writing location.
- Breadcrumb and quick navigation across project and document context.

## Export and output
- Export to HTML, Markdown, PDF, DOCX, and EPUB (based on enabled options).
- Flexible export scope: whole manuscript, section, page, selected sections, or text selection.
- Export presets for repeat workflows.
- Advanced template manager for page size, margins, typography, header/footer, TOC, and page numbering.
- Export preview with search, zoom, page navigation, and print.

## Account and billing
- Account page with plan and AI usage visibility.
- Self-serve upgrade flows (Standard/Pro).
- Billing portal access for subscription management.

## Designed for writers
- Story-first workflows, not generic docs.
- Practical AI help with human review before applying changes.
- Structured planning plus drafting in one place.
