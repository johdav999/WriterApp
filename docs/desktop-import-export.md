# Windows desktop import and export (Release 1, Prompt 10)

Windows uses native Open and Save pickers through `IDeviceFileDialog`. The Save picker supplies the overwrite confirmation and a sanitized suggested filename. The shared app hides these controls on hosts without a native adapter; iOS can supply its own adapter later.

From **My documents**, import a UTF-8 `.txt`, `.html`, or `.htm` file up to 5 MB as a new local-only document. The file is read, decoded, and sanitized before the document is created in one atomic local write. Text files are HTML-escaped and split into editor paragraphs. HTML imports keep paragraphs, headings, emphasis, lists, blockquotes, code, and safe links. Scripts, images, styles, embeds, forms, event handlers, and unsupported attributes are discarded. Invalid encoding, unsupported file types, empty writing, and cancellation create no document.

In the document workspace, select **Append** or **Replace** before choosing an import file. It affects the selected page in the current section. Append keeps its existing supported HTML and adds the imported writing after it; Replace substitutes that page only. The app commits the new page through the local document store's revision check and then refreshes the editor. A parse failure or canceled picker leaves the page unchanged. If the page changed elsewhere, import stops rather than overwriting it. The usual local sync engine will upload the committed edit for a linked document when available.

The workspace exports the entire local document to `.html` or `.txt`, with sections and pages in order. HTML has a restrictive Content Security Policy and sanitized page markup; text keeps the words and structure. Both work offline without signing in or syncing. Legacy JSON pages must first be opened and saved through the editor to avoid a lossy export. DOCX and PDF remain server-dependent: DOCX is feature-flagged, and those formats require entitlement, cloud content, and separate live verification. They are not offered by this offline first-release flow.

Tests cover format detection, UTF-8 and size limits, active-content removal, literal text escaping, append/replace, revision conflict, cancellation, write failure, and Windows-safe filenames. Before release, exercise both native pickers on Windows, including cancel, overwrite/no-overwrite, a denied destination, rich HTML import, multi-section export, and a linked document syncing after import. The iOS file-dialog adapter remains a later platform task.
