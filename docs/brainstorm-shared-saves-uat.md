Shared writes acquire the same document lock as collaboration commits and membership changes. Page changes retire old generations and revoke their leases/sessions. Reviewed structure/planning writes use permits inserted and removed within that serializable transaction; ordinary tracked and raw legacy writes remain fenced. New migrations install planning permits and shared-aware planning sync triggers for SQLite and SQL Server. Undo of a new section tombstones its page and retains snapshots/legacy rows. Original-copy recovery creates a separate private document owned by the requesting actor.

The SQL Server checks also exposed a mode-only conversion updating derived legacy timestamp columns after a planning trigger had changed `UpdatedAt`. Derived timestamps now change only when their source timestamp changes, preserving the mode transition fence. Shared source fingerprints include document-scoped outline, cards, scene notes and page notes, so planning changes invalidate earlier context without exposing project siblings.
