# Prosa AI Tools

This page lists the AI features available in Prosa for writers.

## 1. Rewrite selection
- What it does: Rewrites selected text while keeping meaning.
- When to use it: When a paragraph feels rough but the idea is correct.
- How to use it:
  1. Select text in the editor.
  2. Open **Writing tools**.
  3. Run a rewrite action (for example neutral rewrite).
  4. Review and apply/discard.
- Example outcome: A clunky paragraph becomes cleaner and easier to read.

## 2. Tighten (selection or section)
- What it does: Makes text shorter and more direct.
- When to use it: When prose feels wordy.
- How to use it:
  1. Select text or keep section scope.
  2. Run **Tighten**.
  3. Compare before/after and apply.
- Example outcome: 180 words reduced to 130 words with same meaning.

## 3. Expand (selection or section)
- What it does: Adds detail while preserving intent.
- When to use it: When a scene is too sparse.
- How to use it:
  1. Select text or use section scope.
  2. Run **Expand**.
  3. Apply if it improves depth.
- Example outcome: A brief scene gains sensory detail and context.

## 4. Change tone
- What it does: Rewrites text to a different tone.
- When to use it: When voice should be more friendly, technical, dramatic, or calm.
- How to use it:
  1. Select text or run at section level.
  2. Choose a tone-based action.
  3. Review and apply.
- Example outcome: Formal language becomes warmer and more conversational.

## 5. Show, don’t tell
- What it does: Converts abstract statements into concrete prose.
- When to use it: When writing feels explanatory instead of vivid.
- How to use it:
  1. Select text or use section scope.
  2. Run **Show, don't tell**.
  3. Apply if imagery and action improve.
- Example outcome: "She was nervous" becomes physical and behavioral cues.

## 6. Propose next paragraph
- What it does: Suggests a continuation for the current scene.
- When to use it: When you are stuck on what comes next.
- How to use it:
  1. Open **Writing tools**.
  2. Run **Propose next paragraph**.
  3. Insert or adapt the suggestion.
- Example outcome: A 10-12 sentence continuation that carries momentum forward.

## 7. Translation (selection, section, document)
- What it does: Translates your writing to another language.
- When to use it: When preparing multilingual drafts or alternate-language versions.
- How to use it:
  1. Run a **Translate** action.
  2. Set source and target language.
  3. Review proposal.
  4. Apply as replace or duplicate (for supported scopes).
- Example outcome: Current section translated to Spanish while structure stays intact.

## 8. Scene card Coach
- What it does: Suggests and refines scene metadata.
- When to use it: Before drafting or while fixing scene intent.
- How to use it:
  1. Open **Story tools > Scene card Coach**.
  2. Run one of:
     - Suggest from text
     - Refine
     - Find open questions
  3. Apply or discard the proposal.
- Example outcome: Scene purpose, emotional beat, and open questions are clarified.

## 9. Synopsis AI coaching
- What it does: Reviews synopsis fields and suggests improvements.
- When to use it: During planning before drafting heavily.
- How to use it:
  1. Open **Synopsis**.
  2. Use:
     - **Evaluate synopsis**
     - **Ask guiding questions**
     - **Suggest alternative** for a selected field
  3. Apply suggestion to a field if useful.
- Example outcome: Stronger logline and clearer stakes in synopsis.

## 10. Consistency Coach (continuity)
- What it does: Checks character/place/timeline consistency and suggests minimal fixes.
- When to use it: During revision passes to catch contradictions.
- How to use it:
  1. Open **Consistency Coach**.
  2. Click **Update Bible**.
  3. Click **Check current section**.
  4. Review issues and jump to text.
  5. Apply suggested fix when available.
- Example outcome: Detects conflicting timeline details and proposes a corrected sentence.

## 11. Style & quality Coach
- What it does: Finds readability and quality issues.
- When to use it: During line editing.
- How to use it:
  1. Open **Style & quality Coach**.
  2. Choose scope and filters.
  3. Run quality check.
  4. Review each issue and apply/dismiss.
- Example outcome: Flags repeated words and long sentences, then proposes cleaner edits.

## 12. Prompt library (custom AI presets)
- What it does: Lets you save reusable AI prompts/actions.
- When to use it: For repeat workflows you run often.
- How to use it:
  1. Open **Advanced > Prompt library**.
  2. Create a preset (builtin or custom template).
  3. Save and optionally pin it.
  4. Run it on selection or section.
- Example outcome: One-click “Deepen Character” preset used across scenes.

## 13. AI history and undo/redo
- What it does: Tracks AI commands and supports AI-specific undo/redo.
- When to use it: When comparing or reverting AI edits.
- How to use it:
  1. Open **History**.
  2. Filter by snapshots or AI commands.
  3. Open details to compare before/after.
  4. Use **AI Undo** or **AI Redo** when needed.
- Example outcome: Reverts an applied rewrite without losing the rest of the scene.

## Notes about limits
- AI availability depends on your plan and token quota.
- If quota is reached, Prosa shows usage details and upgrade options.
